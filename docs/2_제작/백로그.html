5챕터 흐름 재정비 (2026-11-21 구현과 대조)

기획서 4쪽과 C-47에서 시작한 점검을 C-56과 현재 코드에 맞춰 다시 정리했어요. 완료한 일과 남은 일을 구분해요. 남은 기획은 사용자와 하나씩 정하고 구현하며, 2~4챕터의 복선(머리 불 색, 숨긴 간식)과 맞춰요.

완료한 일 - [x] A1 · A2 · A4 · A5 · A6 · A7: C-56 흐름. 사탕 · 도깨비 하트 대신 주인공 하트 3개, 요청 물건은 고르면 빼앗김, 맞설 물건은 쪽지를 들이밂, 배드 엔딩 삭제. 결정 기록 - [x] B2: 5챕터 판정 대기는 초록 도깨비가 찾아다니는 화면 대신 빛나는 쪽지와 흑화 도깨비로 바꿈. - [x] C2: 하트가 깎일 때 튀고 흔들리는 효과. - [x] C3: 그리는 동안 흑화 도깨비가 쪽지 곳곳에서 나타났다 사라지고, 도깨비불 · 낙서 · 붉은 막이 움직임. 터치와 그림 · 판정은 그대로 통과함. - [x] C4: 하트 0이면 친구가 화면 안쪽으로 쓰러지고, 영혼이 떠올라 도깨비에게 날아가 사라짐. - [x] 쪽지를 들이밀면 도깨비가 움찔한 뒤 판정 대기로 넘어감. 사탕 먹기 · 쪽지 읽기는 없음.

A. 이야기가 안 맞는 곳 - [x] A3. 맞설 물건을 아는 이유: 2~4챕터 끝 장면 복선 + 5챕터 친구 귓속말 (C-59, 11/23).

B. 그림이 안 맞는 곳 - [x] B1. 흑화 뒤 대사 상자 얼굴을 흑화 얼굴로 (아트팀 얼굴 색 바꿈 임시, C-60, 11/23). - [x] B3. 점프스케어 얼굴을 흑화 얼굴 그림체로 (codex 임시, C-60, 11/23). - [x] B5. 해피 엔딩 : 정화된 도깨비가 뛰어서 도망가고 방망이만 남음 (C-61, 11/23). - [x] B7. 게임오버 : 사람 더미를 도깨비 등 뒤에, 더미 위에 친구 영혼 (C-61, 11/23). - [x] B9. 고르기 카드를 쪽지 종이 질감으로 (C-60, 11/23).

C. 애니메이션이 없는 곳 - [x] C1. 흑화 : 부르르 떨며 숲과 몸이 어두워지고 번쩍 한 뒤 흑화 모습으로 번짐 (C-61, 11/23). - [x] C5. 2단계부터 도깨비는 걸어 들어오지 않고 제자리 (C-61, 11/23). - [x] C6. 엔딩 2개 연출 : 해피는 도망, 게임오버는 더미 앞에서 커지며 다가옴 (C-61, 11/23). - [x] 사탕 통 다시 넣기 : 1~4챕터 끝 장면 + 5챕터 해피 엔딩. 남은 사탕(5챕터는 남은 하트)이 통에 모임 (C-61, 11/23). - [x] 쪽지 → 물건 : 결과 화면에서 빛나는 쪽지가 번쩍 하며 물건으로 바뀜 (C-61, 11/23).

11/18에 꼭 넣기로 한 방해 연출(C3)과 친구 영혼 연출(C4)은 위 완료 목록으로 옮겼어요.

D. 소리 - [x] D1. 5챕터 흑화 뒤 대화·그리기·판정·게임오버는 bgm_curse(bgm_judge 를 느리고 낮게 바꾼 임시 곡), 해피 엔딩은 소풍 곡 (C-62, 11/23). 사운드팀 교체 요청에 임시로 표시.

다음에 정할 순서 1. A3: 맞설 물건을 아는 이유와 친구의 역할. 2. B1 · B3 · B9: 얼굴 · 점프스케어 · 고르기 카드의 그림 통일. 3. C1 · C5 · C6와 B5 · B7: 흑화 · 단계 전환 · 엔딩 연출. 쪽지에서 물건이 나오는 연결도 함께 검토. 4. D1: 5챕터 전용 배경음.
