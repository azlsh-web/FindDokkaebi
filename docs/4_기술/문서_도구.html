문서 도구

상태 최신 · 담당 개발 · 마지막 갱신 2026-11-20

문서를 다시 만들고, 대사 수정을 받고, 문서 사이트를 올리는 방법이에요. 문서 경로는 모두 Tools/docs/paths.py 한 파일에 모여 있어요. 문서를 옮기거나 이름을 바꾸면 이 파일만 고쳐요.

문서 갱신

게임이 바뀌면 아래 명령 하나로 자동 문서를 전부 다시 만들어요. AI 판정은 보내지 않아요. Unity가 켜져 있어야 사진이 찍혀요. 약 6분 걸려요.

python Tools/docs/update_docs.py --shots
  • 자동 문서: 게임 플로우, 플로우 사진, 대사 트리, 대사 수정표, 아트팀 · 사운드팀 전달사항, 아키텍처, 아트 구조.
  • 문서가 게임과 어긋나면: 도구가 멈추고 알려 줘요. 예를 들어 소리 이름을 코드에서 바꾸고 요청 목록을 안 고치면 멈춰요.
  • 자동으로 안 되는 것: 연출 기획, 마일스톤, 결정 기록, 이 문서, 아키텍처 설명 글(Tools/docs/make_arch_doc.py)은 사람이 판단해서 고쳐요. 링크로 공유한 페이지도 다시 올려야 해요.
  • Python: 그림 라이브러리(Pillow)가 있는 Python으로 실행해요. 이 컴퓨터에서는 python이 msys64 쪽을 먼저 찾을 수 있어서, 안 되면 py나 Python313\python.exe로 실행해요.

커밋할 때 자동으로 하기 (켜야 동작해요)

아래 설정을 켜면 게임 파일이 바뀐 커밋에서 위 명령이 자동으로 실행되고, 다시 만든 문서가 그 커밋에 함께 들어가요. 저장소마다 한 번만 켜면 돼요.

git config core.hooksPath .githooks
바뀐 것 자동으로 하는 일
게임 코드, 씬, 그림, 단계 데이터, 소리, 글꼴 플로우 사진을 다시 찍고 자동 문서 전부 다시 만들기 (약 6분)
문서 스크립트와 데이터 사진 없이 문서만 다시 만들기 (약 1분)

Unity가 꺼져 있거나 Play 중이면 경고만 하고 이전 사진을 그대로 써요.

문서를 만들기 전에 Tools/hooks/check_commit.py가 먼저 규칙을 확인해요.

확인하는 것 어기면
게임 코드(Assets/Scripts, Assets/Editor의 .cs)가 바뀌었으면, 그 코드로 돌린 전체 테스트가 PASS인지 (Temp/SelfTest/result.txt) 커밋을 막아요. 급하면 SKIP_TEST_CHECK=1 git commit ...
씬 파일(.unity)이 바뀌었는데 씬 조립 도구는 그대로인지 경고만 해요 (씬을 손으로 고쳤을 수 있어요)

부분 테스트 결과로는 통과하지 않아요. 커밋 전에 전체 테스트를 한 번 돌려요.

대사 수정 받기

기획자에게 대사 수정표를 보내고, 돌려받은 파일을 아래 명령으로 검사한 뒤 반영해요. 반영하면 대사 트리와 수정표도 새로 만들어져요.

python Tools/docs/apply_dialogue_edits.py 받은파일.xlsx

python Tools/docs/apply_dialogue_edits.py 받은파일.xlsx --apply

자동 테스트

Unity 에디터가 켜져 있으면 Temp/mvp_selftest.flag 파일을 만드는 것만으로 테스트가 돌아요.

  • 파일에 그룹 이름을 적으면 그 그룹만 돌려요. 비워 두면 전체예요.
  • 결과는 Temp/SelfTest/result.txt 마지막 줄에 나와요 ([SelfTest] 전체 PASS (n개)). 화면 사진도 같은 폴더에 찍혀요.
  • 작업 중에는 고친 곳의 그룹만 돌리고, 전체는 커밋 전에 한 번 돌려요.
  • Unity 창이 뒤에 있으면 늦게 시작할 수 있어요. 요청 파일이 사라지면 시작된 거예요.

문서 사이트

주소: https://azlsh-web.github.io/FindDokkaebi/docs/ (공개). 웹 게임은 한 단계 위인 https://azlsh-web.github.io/FindDokkaebi/에 있어요.

  • 올리기: feature/game-feel에 Docs 폴더가 바뀐 커밋을 푸시하면 GitHub Actions(.github/workflows/docs-site.yml)가 몇 분 안에 다시 만들어 gh-pages의 docs/ 폴더에 올려요. 웹 게임 파일은 건드리지 않아요.
  • 만드는 도구: Tools/docs/make_docs_site.py. 내 컴퓨터에서 미리 보려면 python Tools/docs/make_docs_site.py를 실행하고 Temp/DocsSite/index.html을 열어요.
  • 목록: 사이트 홈의 카드는 시작하기의 구역별 표에서 읽어요. 새 문서는 그 표에 한 줄 넣어야 설명과 함께 나와요. 표에 없는 파일은 카드 이름만 나와요.
  • 옛 주소: 폴더를 바꾸기 전 주소(전달/아트.pdf 등)로 들어와도 열리게, 사이트에 옛 주소를 남겨요. 목록은 paths.py의 LEGACY예요.
  • Docs 밖 문서: 저장소 맨 위의 BACKLOG.md는 사이트에서 "제작 → 백로그"로 보여요. 목록은 paths.py의 EXTERNAL_PAGES예요.
