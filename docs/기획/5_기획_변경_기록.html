변경 내용

C-01. 방망이 그림

새 방망이 그림은 머리에 돌기와 구멍이 있고, 손잡이에 가로 줄 대신 리본이 있어요. 판정 문구도 이 그림에 맞췄어요.

C-02. 돗자리 띠 방향

새 돗자리 그림은 띠가 가로로 놓여 있어서, 띠 순서를 위에서 아래 기준으로 판정해요.

C-03. 판정 기준

레벨이 올라갈 때마다 평가 요소가 하나씩 늘어나요. 원본에 다른 특징이 더 있어도 아래 기준만 판정해요.

단계 물건 형태 패턴 삼원색 2색 혼합 3색 혼합
1 방망이 굵은 머리 + 돌기
2 가방 네모 몸체 + 위쪽 손잡이 + 앞주머니 주머니 안 가로 줄무늬
3 돗자리 사각형 외곽 띠 네 줄 파랑·빨강·노랑·파랑 순서
4 김밥 둥근 검은 김 테두리 위 둘, 아래 하나인 재료 배치 노란 단무지 초록 시금치
5 친구 양 갈래 머리 주머니 천 조각 파란 바지 주황 상의 갈색 머리
  • 이전 기준에서 빠진 것: 김밥의 흰 밥과 빨간 재료, 친구의 사람 모습은 판정하지 않아요.
  • 3색 혼합: 원본의 갈색 머리는 빨강·노랑·파랑을 섞은 색이고, 게임도 3색까지 섞을 수 있어요.

C-04. 돌려주는 물건

기준이 n개면 경우의 수는 2ⁿ가지이고, 조합마다 정해진 그림을 돌려줘요.

판정 결과 돌려주는 것
전부 맞음 원본 A
일부만 맞음 그 조합대로 틀린 A'
전부 틀림 완전히 다른 물건 B
  • 완전히 다른 물건 B: 방망이는 대파, 가방은 항아리, 돗자리는 파전, 김밥은 고무신, 친구는 허수아비예요.
  • 1단계: 기준이 하나라 A'가 없고, 틀리면 바로 대파가 와요.
  • 전체 목록: 6_엉뚱한_물건_제작.md

C-05. 판정 기준 안내

단계 도입 화면에 이번 판정 기준을 보여 줘요. 플레이어는 기준을 알고 원본을 관찰해요.

C-12. 오프닝과 대사

2026-11-05에 기획자가 전달한 대사를 적용했어요. 오프닝은 필수 적용, 나머지는 참고 사항이었어요.

대상 적용 내용
오프닝 기획자 문구 그대로. 대사 상자의 세 줄을 넘는 두 대사만 문장 단위로 나눠 12줄이 됐어요
1단계 쪽지 판정 기준을 지우면 쪽지에 제목만 남아서, 쪽지를 건너뛰고 바로 관찰해요. 채점표의 기준 이름은 그대로예요
2·3단계 시작 대화 기획자 문구로 교체. 4·5단계는 받은 안이 없어 그대로예요
주인공 판정 대사 기획자 문구로 교체. 플레이어가 그리는 설정과 맞지 않던 내 그림이 그렇게 이상해?! 같은 대사가 빠졌어요
판정 오류 · 간식 소진 대사 기획자 문구로 교체
도깨비 결과 대사 단계별 대사 유지. 엉뚱한 물건에 맞춘 농담을 살리기 위해서예요
일시정지 음량 · 효과음 조절 아직 없음. 기획자 메모대로 BGM을 넣은 뒤 추가해요

화면 구조 (기획 변경 아님)

시작 화면을 통그림 대신 배경 위에 물건을 하나씩 올리는 구조로 바꿨어요. 시작 화면 배경은 BG_Start, 게임 중 배경은 BG_Room이고, 맨 뒤 배경 한 장만 바꿔요.

그리기 화면의 향은 놋쇠 촛대에 꽂혀 타요. 불꽃이 줄기를 따라 내려오고, 재가 떨어지고, 연기가 올라가요. (11/7) 아트팀 그림으로 바꾸면서, 재는 불씨 위에 쌓였다가 뚝 떨어지고 불꽃은 쌓인 재 위에 얹혀 같이 오르내려요. 10초 남으면 불꽃이 커지고 남은 초가 빨갛게 두근거려요.

그리기 화면 배치와 HUD 개편 (기획 변경 아님)

2026-11-04에 플레이하기 쉽게 배치를 바꿨어요. 판정 기준과 게임 규칙은 그대로예요.

  • HUD: 로고와 단계 표시(1/5 · 방망이)를 게임 중 모든 화면에서 뺐어요. 위에는 복주머니 3개와 일시정지만 남아요. 단계 번호와 물건 이름은 도입 화면에서 보여 줘요.
  • 간식: 글자 대신 복주머니로 보여 줘요. 쓴 간식은 왼쪽부터 흐려져요.
  • 그림판: 클립보드의 하얀 면 전체에 그려져요. 크기는 512×512에서 512×604로 바뀌었고, 제목 글자 밑에도 그릴 수 있어요. 제목은 제출하는 그림에 들어가지 않아요.
  • 도구 줄: 모두 지우기를 쪽지 모서리에서 도구 줄로 옮겼어요. 물감 줄과 도구 줄의 양 끝도 맞췄어요.
  • 펜 굵기: 그림판이 커져도 화면에서 굵기가 비슷하도록 펜 반지름을 3 · 6 · 12에서 3 · 5 · 10으로, 지우개를 18에서 15로 바꿨어요.
  • 치운 그림: HUD_Capsule, HUD_LogoMark, Draw_Clipboard는 ArtSource/원본/미사용으로 옮겼어요. 지금 틀은 Draw_ClipboardFrame이에요.
  • 미확인: 세로로 길어진 그림을 실제 AI 판정으로 시험하지는 않았어요. 경우의 수 테스트 보고서의 화면과 입력 그림도 개편 전 512×512 기준이에요.

화면별 표시 정보

연출 개편 뒤 기준이에요. 설명 글과 제목을 빼고, 한 화면에서 같은 정보를 두 번 보여 주지 않아요. 화면 사진은 게임 플로우에 있어요.

화면 표시하는 정보
1. 시작 로고, 캐릭터, 게임 시작하기
2. 대화 캐릭터, 말하는 사람의 얼굴, 대사. 1단계 처음에는 사라지는 준비물
3. 떠올리기 말풍선 속 원본, 숫자, 떠올리는 캐릭터 (1단계는 도깨비)
4. 쪽지 쓰기 남은 간식, 쪽지 글, 향과 남은 초, 색, 도구, 굵기, 다 그렸어!, 맨 위 돋보기 · 초콜릿 · 사탕 (C-19 · C-20)
5. 건네기 남은 간식, 그림과 글이 적힌 쪽지, 캐릭터, 대사
6. 판정 대기 남은 간식, 내 쪽지, 찾으러 다니는 도깨비
7. 결과 남은 간식, 도깨비, 가져온 물건, 대사, 다시 · 포기
8. 채점표 내 그림, 원본, 번호와 판정 기준, 동그라미 또는 빗금
9. 이야기 종료 소풍 장면, 물건, 물건 옆 남은 간식, 도깨비 대사
