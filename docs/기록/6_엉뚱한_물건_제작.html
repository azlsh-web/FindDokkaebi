엉뚱한 물건 제작

물건별로 돌려주는 그림을 Codex로 만들어 Unity에 연결한 작업 기록이에요. 57장 모두 연결을 마쳤어요. 작업에 쓴 Assets/TempArt는 정리하며 지웠어요. 그림을 다시 만들 때는 빈 작업 폴더를 만들고, Assets/Sprites의 물건 원본을 Original-물건.png 이름으로 복사한 뒤 아래 프롬프트의 경로를 바꿔 쓰면 돼요.

마지막 갱신: 2026-11-04

게임 규칙

그림을 판정 기준별로 맞음(O) · 틀림(X)으로 나눠, 그 조합에 정해진 물건을 돌려줘요. 기준이 n개면 경우의 수는 2ⁿ이에요.

판정 결과 도깨비가 가져오는 것
전부 맞음 원본 A
일부만 맞음 닮았지만 틀린 A'
전부 틀림 완전히 다른 물건 B

작업 순서

  1. Codex에서 작업 폴더를 지정하고, 아래 프롬프트를 붙여 넣어요.
  2. 그림 57장이 작업 폴더에 폴더 없이 저장돼요.
  3. 그림을 확인하고 배경을 지운 뒤 Assets/Sprites/단계 폴더에 넣어 Unity에 연결해요.

Codex 프롬프트

게임에 넣을 '엉뚱한 물건' 그림 57장을 이미지 생성 기능으로 모두 만들어 주세요.

[작업 폴더]
(빈 작업 폴더의 경로)

[원본]
작업 폴더의 Original-Bat.png, Original-Bag.png, Original-Mat.png, Original-Gimbap.png, Original-Friend.png를 직접 열어 입력 이미지로 사용하세요.

[저장]
- 하위 폴더를 만들지 말고 작업 폴더 바로 아래에 PNG 파일 57개를 나란히 저장
- 파일 이름은 아래 목록 그대로 쓰고 끝에 .png를 붙이기
- 작업 폴더의 기존 파일과 프로젝트의 다른 파일은 수정하거나 지우지 않기
- 코드나 그림 그리기 스크립트로 그림을 그리지 말고, 이미지 생성 기능을 쓸 수 없으면 바로 멈추고 알려 주기

[모든 그림에 공통으로 지킬 것]
- 앞서 만든 결과물이 아니라 해당 원본을 바탕으로 매번 새로 편집
- 바꾸라고 한 부분 말고는 모양, 색, 각도, 선 굵기, 채색 방식을 원본과 똑같이 유지
- 새 장식, 소품, 글자, 그림자 추가 금지
- 물건은 가운데에, 잘리지 않게, 둘레에 여백을 두고 배치
- 정사각형 1024×1024
- 배경 전체를 단색 마젠타(#FF00FF)로 채우기. 투명 체크무늬와 그라데이션 금지
- 그림 한 장에 물건 하나만 그리기

[진행]
- 중간에 확인을 묻지 말고 57장을 끝까지 만들기
- 끝나면 저장한 파일 수와, 못 만든 파일이 있으면 그 이름을 알려 주기
