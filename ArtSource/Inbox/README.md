# 아트 업로드 폴더

완성한 그림을 올리는 곳이에요. 프로그램 설치 없이 GitHub 웹사이트에서 올리면 돼요.
이 폴더에 올려도 게임은 바로 바뀌지 않으니, 편하게 올려 주세요. 게임 연결은 개발 쪽에서 해요.

## 올리는 방법

1. 이 폴더(`ArtSource/Inbox`)를 연 채로 오른쪽 위 **Add file → Upload files** 를 눌러요.
2. 그림 파일이나 폴더를 화면에 끌어다 놓아요.
3. 아래쪽에서 **Create a new branch for this commit and start a pull request** 를 골라요.
4. **Propose changes** 를 누르고, 다음 화면에서 **Create pull request** 를 눌러요.

여기까지 하면 끝이에요. 개발 쪽에서 확인하고 합칠게요.

## 파일 규칙

- 폴더 구조와 파일 이름은 `Docs/3_아트_요청_목록.pdf` 5장 그대로 맞춰 주세요. (예 : `Stage1_Bat/Original.png`)
- 파일 하나는 25MB 까지, 한 번에 100개까지 올릴 수 있어요.
- 수정본은 **같은 이름**으로 다시 올려 주세요. 예전 버전은 GitHub 에 남아 있어요.
- 이 저장소는 공개라서 올린 그림을 누구나 볼 수 있어요.
