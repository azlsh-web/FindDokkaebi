# 아트 원본 정리 (게임 플로우 순서)

기획서 그림과 첨부 사진이 게임의 어느 화면에 들어가는지, 통째로 쓰는지 일부만 오려 쓰는지 정리했어요.

- `원본/기획서` : 「게임기획서_아트 수정.docx」 그림 1~24
- `원본/첨부` : 폴더에 첨부한 사진 8장
- `화면별/NN_화면` : 그 화면에 들어간 그림·부품 (원래 크기). 게임 안에는 `Assets/Sprites/` 에 있어요 (시안 UI 는 절반 크기)
- 좌표는 시안 그림(2248×3952) 픽셀이에요. 오린 방법은 `Docs/src/art_pipeline/*.py`
