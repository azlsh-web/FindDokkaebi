## src/ (문서 · 그림을 만드는 스크립트)

| 파일 | 만드는 것 |
|---|---|
| `make_docs.py` | `1_게임_플로우.pdf` · `2_MVP_아키텍처.pdf` (자동 플레이 테스트 캡처 사용) |
| `organize_art.py` | `ArtSource/` 정리 |
| `art_pipeline/` | 시안에서 UI 부품 오리기 · 가장자리 다듬기 · 절반 크기 · 「그림 준비 중」 그림 |
| `make_judge_report.py` · `make_art_report.py` · `make_attached_report.py` | `참고/` 의 예전 PDF 들 |

문서 다시 만들기 (자동 플레이 테스트 캡처가 `Temp/SelfTest` 에 있을 때):

```
python Docs/src/make_docs.py . Temp/SelfTest
```
