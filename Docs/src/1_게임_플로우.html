찾아라! 도깨비 — 게임 플로우

실제 게임 화면이 어떤 순서로, 어떤 조건에서 넘어가는지. 캡처는 자동 플레이 테스트가 찍은 지금 버전 화면이에요.

한눈에 보기

1 시작→2 단계 도입→3 관찰 3초→4 그리기 60초→5 판정 대기 (AI)→6 결과→7 비교→다음 단계 / 8 이야기 종료
결과에 따라다음
특징을 전부 그림 → 성공 (진짜 물건)「내 그림과 비교하기」 → 7 비교 → 다음 단계
일부만 그림 → 부분 성공 (엉뚱한 물건)간식이 남았으면 「다시 그리기」(원본 안 보여 주고 4 그리기, 60초) 또는 「포기하고 비교하기」
하나도 못 그림 → 아무것도 못 찾음부분 성공과 같음
간식 0개가 됨「다시 그리기」 없음 → 「포기하고 비교하기」만
AI 판정 실패 (인터넷 · 서버 · 키)간식을 돌려주고 「그림으로 돌아가 다시 제출」 (그리던 그림 그대로, 남은 시간 최소 10초)
향이 다 탐 (60초)지금 그림 그대로 자동 제출
일시정지 (오른쪽 위)어느 화면이든 시간 멈춤 → 「계속하기」
간식 : 단계마다 3개로 시작, 제출할 때 1개 씀. 5단계(방망이 → 가방 → 돗자리 → 김밥 → 친구)를 마치면 이야기 종료. 판정은 AI 가 해요 (그림 + 단계별 특징 기준 → 특징마다 그림/빠뜨림). 그림이 들어간 곳은 ArtSource/README.md.

화면 순서대로

1. 시작 화면

나오는 것팀 시작 화면 그림 (제목 · 주인공 · 도깨비 · 「소풍 준비하러 가기」)
하는 것「소풍 준비하러 가기」 누르기
다음1단계 단계 도입. 기록(단계별 성공·제출 수·남은 간식)을 새로 시작
그림ArtSource/화면별/01_시작화면

2. 단계 도입

나오는 것위 HUD (로고 · 「1/5 · 방망이」 · 일시정지 · 간식 3개), 단계 번호 · 물건 이름 · 주인공과 도깨비 · 이야기, 새로 배울 규칙 · 앞에서 배운 규칙 · 시간 안내
하는 것읽고 「기억할 모습 보기」
다음관찰 (3초)
바뀌는 값간식 3개로 채움, 단계에 맞는 색 버튼 준비 (1·2단계 검정 / 3단계 + 빨노파 / 4·5단계 + 섞은 색 · 색 섞기)
그림화면별/02_단계도입 + 공통 카드 · 버튼

3. 관찰 (3초)

나오는 것카드 위로 빼꼼한 도깨비 「잘 봐 둬! 곧 숨긴다?」, 테이프 쪽지 속 물건 원본 · 이름 · 「모양(과 색)을 눈에 꼭 담아 줘!」, 3 · 2 · 1 (지금 숫자만 코랄)
하는 것모양 · 무늬 · 색을 기억하기 (누를 것 없음)
다음3초가 지나면 자동으로 그리기. 원본은 다시 안 보여 줘요
그림화면별/03_관찰, 물건은 화면별/10_단계별물건

4. 그리기 (60초)

나오는 것클립보드 쪽지 「기억나는 김밥을 그려 줘」, 오른쪽 긴 향(타들어 감) + 남은 초, 물감 판(단계마다 쓸 수 있는 색), 연필 · 지우개 · 되돌리기 · 굵기 3단계, 쪽지 오른쪽 아래 모두 지우기, 「다 그렸어! 간식 1개 사용」
하는 것기억한 특징을 그리기. 4·5단계는 「색 섞기」로 색을 만들어 칠하기 (아래 4-1)
다음「다 그렸어!」 또는 60초가 지나면 → 판정 대기. 빈 쪽지면 「다 그렸어!」 · 되돌리기 · 모두 지우기가 꺼져 있음
바뀌는 값제출하면 간식 −1, 이 단계 제출 횟수 +1
그림화면별/04_그리기

4-1. 색 섞기 (4·5단계, 그리기 중)

나오는 것물감 판과 도구 줄 자리를 덮는 카드 : 재료 색(빨강 · 노랑 · 파랑) 고르기, 결과 색 미리보기 · 「노랑 + 파랑 = 초록」, 「섞어서 칠하기」, 닫기
규칙4단계는 두 색만 (노랑+파랑=초록, 빨강+노랑=주황, 빨강+파랑=보라), 5단계는 세 색까지 (빨강+노랑+파랑=갈색)
다음「섞어서 칠하기」 → 카드가 닫히고 그 색이 물감 판 5번째 칸에 들어가 골라져요

5. 판정 대기

나오는 것「쪽지와 간식 1개를 도깨비에게 건넸어요. 도깨비가 쪽지를 들여다보는 중...」, 갸웃거리는 도깨비 · 건넨 쪽지 · 간식
판정그림(PNG) → 판정 서버 → AI(Google Gemini) 가 단계별 특징 기준(기획서 부록 B 프롬프트)으로 특징마다 present / absent / uncertain + 근거
다음판정이 오면 결과. 실패하면 (캡처) 「판정 중에 문제가 생겼어요. 간식을 돌려줬어요」 + 「그림으로 돌아가 다시 제출」

6. 결과 — 부분 성공

나오는 것도깨비 · 가져온 물건 · 내 그림, 「엉뚱한 방망이를 가져왔다...」, 특징별 [O] 그림 / [X] 빠뜨림 (+ 빠뜨린 이유), 소년 「'볼록볼록한 머리' 부분이 달라!」, 남은 간식
가져온 물건처음 빠뜨린 특징에 맞는 엉뚱한 물건 (지금은 팀 그림이 없어 「그림 준비 중」)
하는 것「다시 그리기 (간식 1개)」 → 그리기 (60초, 원본 다시 안 봄) / 「포기하고 비교하기」 → 비교

6. 결과 — 성공

나오는 것「도깨비가 방망이를 찾아왔다!」, 진짜 물건, 특징 전부 [O], 소년 「찾았다! 바로 이 방망이야!」
하는 것「내 그림과 비교하기」 → 비교

6. 결과 — 간식이 다 떨어짐

나오는 것「도깨비가 아무것도 찾지 못했다...」(하나도 못 그림), 「간식이 다 떨어졌어요. 원본과 비교하고 넘어가요.」
하는 것「포기하고 비교하기」만 있음 → 비교 (이 단계는 기록에 「포기했어요」)

7. 비교

나오는 것왼쪽 내 그림 · 오른쪽 원본, 원본의 특징 목록
하는 것「다음 단계로」 (5단계에서는 「오늘의 이야기 마치기」)
다음다음 단계 도입 (간식 다시 3개) / 5단계 뒤에는 이야기 종료

8. 이야기 종료

나오는 것「오늘의 이야기 끝!」, 주인공 · 도깨비 · 친구, 단계별 기록 (찾았어요/포기했어요 · 제출 수 · 남은 간식)
하는 것「처음으로」 → 시작 화면

단계마다 다른 것

단계물건쓸 수 있는 색판정할 특징

3돗자리검정 · 빨강 · 노랑 · 파랑사각형 외곽 · 띠 네 줄 · 두 번째 띠 빨강 · 세 번째 띠 노랑 · 양 끝 띠 파랑
4김밥+ 두 색 섞기검은 김 테두리 · 흰 밥 · 빨간 · 노란 · 초록 재료
