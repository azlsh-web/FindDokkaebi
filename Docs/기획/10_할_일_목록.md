## 돋보기 규칙

2026-11-11에 정했어요. 돋보기는 **초콜릿**을 써서 보고, 쪽지는 **사탕**을 함께 건네요.

| 정한 것 | 내용 |
|---|---|
| 간식 | 단계마다 사탕 2개(쪽지 건네기)와 초콜릿 2개(돋보기)를 새로 받아요. 맨 위 줄은 왼쪽부터 돋보기, 초콜릿(돋보기에 붙여서), 사탕, 일시정지 순서예요. |
| 쓰는 방법 | 그리는 중에 맨 위 왼쪽 돋보기를 누르면 바로 둘러봐요. |
| 값 | 초콜릿 1개. 쓴 초콜릿은 오른쪽부터 흐려지고, 초콜릿이 없으면 돋보기도 흐려져서 쓸 수 없어요. |
| 보는 방식 | 화면이 어두워지고, 렌즈 안에만 그림판 자리에 놓인 원본이 보여요. 렌즈는 손가락으로 끌어서 움직여요. 보는 동안은 그릴 수 없어요. |
| 시간 | 3초. 그동안 향은 계속 타요. |
| 단계 | 모든 단계에서 써요. |
