## 돋보기 규칙

2026-11-11에 정하고 2026-11-12에 바꿨어요 (C-23). 초콜릿은 없어졌고, 쪽지는 **사탕**을 함께 건네요.

| 정한 것 | 내용 |
|---|---|
| 간식 | 단계마다 사탕 3개를 새로 받아요. 쪽지를 건넬 때마다 1개. 맨 위 줄은 왼쪽부터 돋보기, 사탕, 일시정지 순서예요. |
| 쓸 수 있는 횟수 | **게임 전체에서 1번.** 돋보기 오른쪽 아래 동그라미 숫자가 지금 쓸 수 있는 횟수예요. 다 쓰면 숫자가 사라지고 돋보기가 흐려져요. |
| 시범 | 1단계 첫 그리기 때 도깨비가 `돋보기를 눌러 봐!`라고 해요. 대사를 넘기면 대사가 사라지고 도깨비불 셋이 돋보기 둘레를 돌며 돋보기가 콩콩 뛰어요 (화면을 눌러도 안 넘어가요). 돋보기를 누르면 보는 법(5초, 렌즈 끌기)을 말하고, 대사를 넘기면 둘러봐요. 닫히면 `한 번만 더 빌려줄게`라고 알려 줘요. **시범은 공짜**이고, 시범 동안은 향이 타지 않아요. |
| 무료 기회 | 한 단계에서 **두 번째로 틀리면** (사탕이 남았을 때) 도깨비가 돋보기를 건네주고, 돋보기가 맨 위 돋보기로 날아가 반짝여요. **그 단계에서만** 쓰고, 안 쓰면 단계가 끝날 때 사라져요. 단계마다 1번. |
| 쓰는 순서 | 무료 기회가 있으면 그것부터 써요. 전체 1번이 남아 있으면 그 단계에서 2번 쓸 수 있어요. |
| 보는 방식 | 화면이 어두워지고, 렌즈 안에만 그림판 자리에 놓인 원본이 보여요. 렌즈는 손가락으로 끌어서 움직여요. 보는 동안은 그릴 수 없어요. 남은 시간은 돋보기 테두리의 호박색 띠가 시계 방향으로 줄어들며 보여 줘요 (마지막 1초는 코랄색, 1초마다 똑딱). |
| 시간 | **5초** (11/12에 3초에서 늘림). 그동안 향은 계속 타요 (시범 때만 멈춰요). |
