## 돋보기에서 정할 것

| 정할 것 | 왜 필요한가 | 제안 |
|---|---|---|
| 처음 개수 | 처음부터 가지고 시작하는지 정해지지 않았어요. | 0개로 시작 |
| 간식과의 관계 | 간식을 쓰는지, 돋보기를 따로 세는지 정해요. | 따로 세기 |
| 언제 얻는가 | 간식이 3개라 2번 틀리면 기회가 1번 남아요. | 2번째 오답에서 얻기 |
| 오답 물건과의 관계 | 지금은 O · X 조합마다 돌려주는 그림이 정해져 있어요. 돋보기가 그 그림을 대신하면 어떤 물건이 왔는지 볼 수 없어요. | 틀린 물건과 함께 주기 |
| 다음 단계로 넘기기 | 남은 돋보기를 다음 단계에서 쓸 수 있는지 정해요. | 넘기기 |
| 시간 | 돋보기를 보는 3초 동안 향이 계속 타는지 정해요. | 계속 타기 |
| 위치 | 돋보기 원을 플레이어가 움직이는지 정해요. | 움직이기 |
