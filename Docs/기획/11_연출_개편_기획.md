## 화면별 기획

### 1. 시작

- 뺄 것: `기억 한 조각, 그림 한 장`, `기억하고, 그리며 소풍을 준비해요`, 설정 버튼.
- 남길 것: 로고, 캐릭터, 시작 버튼. 버튼 글자는 `게임 시작하기`예요.
- `기억 한 조각, 그림 한 장`은 `Title_Logo` 그림에 포함돼 있어요. 아트 요청 없이 그 부분을 직접 지워요.
- 시작 버튼을 누르면 화면이 어두워지며 대화로 넘어가요.

### 2. 단계 시작 대화 + 기준 카드

- **단계 도입 화면을 없애요.**
- **대화창:** 화면 아래에 말하는 캐릭터의 작은 얼굴과 대사가 나와요. 모든 대사는 **가로세로가 같은 상자**에 나오고, 글자는 얇고 작게 써요. 한 글자씩 나오고, 터치하면 넘어가요.
- **얼굴:** 대사에 맞는 표정을 써요. 없는 표정은 임시 그림을 만들고 아트팀에 요청해요.
- **길이:** 모든 단계 2~3줄.
- **기준 카드:** 대사가 끝나면 `도깨비의 쪽지`가 제자리에서 살짝 커지며 빠르게 나타나요. 떨어지거나 펴지는 움직임은 쓰지 않아요. 쪽지가 나오면 캐릭터는 사라져서 가려지지 않게 하고, 쪽지는 대화창 위 빈 공간의 가운데에 놓여요. 판정 기준은 `1. 2. 3.` 번호로 적고, 쪽지와 함께 도깨비가 주의할 점을 말해요. 터치하면 관찰이 시작돼요.
- **쪽지 대사:** 1단계 `여기 적힌 건 꼭 그려 줘. 안 그리면 엉뚱한 걸 가져올 거야!` / 2단계 `이번엔 주머니 안쪽 줄무늬도 꼭 넣어 줘!` / 3단계 `띠의 색 순서가 중요해. 위에서부터 차례로 봐 둬!` / 4단계 `재료 색을 잘 봐 둬. 어떤 색을 섞을지는 네가 찾아봐!` / 5단계 `머리와 옷 색을 잘 봐 둬. 섞다 보면 딱 맞는 색이 나올 거야!`
- **색 조합은 대사로 알려 주지 않아요.** 플레이어가 혼색 팔레트에서 물감을 한 번씩 넣고 빼 보며 찾아요. 빨강 : 노랑 : 파랑을 1:1:1로 넣으면 검은색에 가깝고, 2:2:1로 넣으면 갈색이 돼요.
- **대사 줄바꿈:** 상자 폭에 맞춰 단어 단위로 자동으로 줄을 바꿔요. 한 대사는 상자에 들어가는 3줄 안으로 써요.
- 새 규칙은 도깨비 대사로 전하고, `앞에서 배운 규칙` 칸은 없애요. 판정 기준 목록에 이미 들어 있어요.

#### 대사 초안

포기한 단계가 있어도 어색하지 않게 썼어요.

| 단계 | 대사 |
|---|---|
| 1 방망이 | 주인공(놀람): 소풍 준비물이 모두 어디 갔지?! / 도깨비: 내 방망이도 없어졌어! 쪽지에 그려 주면 찾아 올게. / 도깨비: 간식 한 개면 돼. 잘 기억해 둬! |
| 2 가방 | 도깨비: 이제 준비물을 담을 가방을 찾자. / 도깨비: 이번엔 무늬도 잘 봐! |
| 3 돗자리 | 주인공: 잔디밭에 펼칠 돗자리도 필요해. / 도깨비: 이번엔 색이 중요해. 순서도 잘 봐! |
| 4 김밥 | 주인공: 소풍에 김밥이 빠질 수 없지! / 도깨비: 없는 색은 두 가지를 섞어서 만들어 봐! |
| 5 친구 | 도깨비: 큰일이야, 네 친구가 길을 잃었대! / 주인공: 같이 가야 하는데! 꼭 찾아 줘. / 도깨비: 이번엔 세 가지 색도 섞어야 해! |

### 3. 관찰

- 원본과 가운데 큰 숫자(3 → 2 → 1)만 남겨요.
- 뺄 것: 물건 이름, 볼 것 안내, 3 · 2 · 1 칸, 도깨비 말풍선.

### 4. 그리기

- 대화와 관찰 동안에는 간식을 숨겨요.
- **단계별 첫 그리기**로 넘어갈 때 간식 3개가 왼쪽 화면 밖에서 같은 높이로 오른쪽을 향해 샤샤샥 들어와요. 맨 오른쪽 칸부터 차요.
- 재도전 때는 남은 간식이 제자리에 그대로 있어요.
- **재도전은 이전 그림에서 이어 그려요.** 향은 다시 60초에서 시작하고, 처음부터 그리고 싶으면 휴지통으로 지워요. 지금 게임은 빈 쪽지로 시작하므로 구현 때 바꿔요.
- **도구 아이콘:** 연필, 지우개, 되돌리기, 휴지통의 긴 변을 원 지름의 56%로 똑같이 맞춰요.
- **향:** 불꽃, 재, 연기는 지금 게임의 연출을 그대로 써요.

### 5. 판정 대기

1. 제출하면 도깨비가 옆에서 살짝 나타나요.
2. 간식 1개를 가져가요. 내 그림은 도깨비가 들고 다니지 않고 화면 한 곳에 떠 있어요.
3. 바닥에 발을 붙이고 방 안을 돌아다니며 찾아요.
4. **찾는 동작은 한 바퀴 6초로 만들어 반복해요. 화면 가운데에서 좁은 범위(화면 폭의 약 6분의 1)만 오가고, 양 끝에서 잠깐 멈추며, 통통 튀지 않게 천천히 걸어요. 응답이 오면 그 바퀴를 마치고 넘어가요.**
5. 위쪽 진행 문구는 없애요.

판정 오류가 나면 도깨비가 돌아와 쪽지를 못 읽었다고 말하고 간식을 돌려줘요. 대사를 누르면 그림으로 돌아가요.

고민하는 도깨비는 아트팀 그림(`Char_Dokkaebi_Think`)을 그대로 써요.

### 6. 결과

1. 화면이 전환되고 도깨비가 물건을 내밀며 말해요.
2. 물건이 바닥에 놓인 채로 크게 나타나요. 공중에 뜨지 않게 그림자를 깔아요.
3. 주인공이 반응해요.
4. 대사를 누르면, 재도전할 수 있을 때는 대사 상자 자리에 `다시`·`포기` 버튼이 나란히 나오고, 아니면 채점표로 넘어가요.

- **특징별 O · X 목록은 빼요.** 틀린 부분은 물건 그림을 보고 추리해요.
- **대사:** 단계별로 성공, 일부 틀림, 전부 틀림 대사를 2~3개씩 두고 무작위로 골라요. 특징 이름은 말하지 않아요.
- **말투:** 틀리면 도깨비는 놀리고, 주인공은 적잖이 당황해요.
- **버튼:** 아이콘 + 한 단어.

| 상황 | 버튼 |
|---|---|
| 틀림, 간식 남음 | 연필 `다시` (복주머니 1개 표시), 깃발 `포기` |
| 틀림, 간식 없음 | 없음. 대사를 누르면 채점표로 |
| 성공 | 없음. 대사를 누르면 채점표로 |

#### 대사 예시

| 상황 | 도깨비 | 주인공 |
|---|---|---|
| 일부 틀림 | 네가 이렇게 그렸잖아~ 난 그대로 찾아왔다고! | 어, 어라?! 이건 아닌데...! |
| 전부 틀림 | 짠! 그림이랑 똑같지? 히히. | 이, 이게 뭐야?! 내 그림이 그렇게 이상해?! |
| 성공 | 어때? 쪽지 보고 바로 찾았지! | 맞아, 바로 이거야! |

### 7. 비교 (채점표)

- 대사와 제목 없이 시험지가 채점되는 것처럼 보여 줘요. `내 그림`, `원본` 이름표도 두지 않아요.
- 내 그림과 원본을 나란히 두고, 판정 기준을 `1, 2, 3...` 번호로 적어요.
- 맞은 번호에는 **초록 동그라미**, 틀린 번호에는 **빨간 빗금**을 위에서부터 차례로 그어요.
- 버튼 없이 화면을 누르면 다음으로 넘어가요.
- AI 판정 근거 문장은 글을 줄이기 위해 보여 주지 않아요.
- **줄바꿈:** 게임 전체에서 단어 중간을 끊지 않아요. 판정 기준은 `+`로 나눈 덩어리째 줄을 바꿔요. 예) `네모 몸체 + 위쪽 손잡이` / `+ 앞주머니`

### 8. 이야기 종료

- 소풍 장소 배경에 돗자리를 펼치고 물건이 하나씩 날아와 자리 잡아요.
- 포기한 단계는 **마지막으로 받은 엉뚱한 물건**이 그대로 놓여요.
- 세 캐릭터가 땅에 발을 붙이고 서서 살랑살랑 움직여요. 위아래로 뜨지 않아요. 친구 단계를 포기하면 허수아비 같은 받은 물건이 친구 자리에 서요.
- 남은 간식은 물건마다 물건 옆에 복주머니로 보여 줘요. 맨 아래 모음은 두지 않아요.
- `소풍 출발!` 같은 글자와 홈 버튼을 두지 않아요.
- 화면을 한 번 더 누르면 도깨비가 처음으로 돌아갈지 물어보고, 그 대사를 누르면 시작 화면으로 돌아가요.

### 도깨비와 방망이

- 1단계 동안 도깨비는 방망이가 없는 빈손 그림이에요. 찾으면 그때부터 방망이를 들어요.
- 1단계를 간식을 다 쓰거나 포기해서 못 찾으면, 도깨비는 2단계부터 이야기 종료까지 **계속 빈손**이에요.
- 이때 이야기 종료의 방망이 자리에는 다른 포기 단계처럼 마지막으로 받은 물건인 대파가 놓여요.

## 애니메이션 · VFX

코드로 움직이고, 표정 그림을 바꿔 끼워요. 캐릭터 움직임은 정신없지 않게 잔잔하게 하고, 등장할 때를 빼면 화면 밖으로 나가지 않아요. 걸을 때 그림을 뒤집지 않아요.

| 대상 | 연출 |
|---|---|
| 화면 전환 | 페이드, 대화 시작 때 어두워지기 |
| 대화 중 캐릭터 | 말할 때 잔잔하게 움직이기, 표정 바꾸기 |
| 관찰 숫자 | 바뀔 때마다 튀어 오르기 |
| 간식 | 순서대로 날아오기, 제출 때 빠져나가기 |
| 도깨비 판정 | 등장, 간식 가져가기, 걷기 반복, 찾으며 두리번거리기, 먼지. 내 그림은 위에 둥실 떠 있기 |
| 물건 등장 | 튀어 오르기, 성공 반짝임, 실패 흔들림 |
| 채점표 | 번호 위에 동그라미와 빗금을 하나씩 긋기 |
| 버튼 | 누를 때 눌림과 튕김 |
| 이야기 종료 | 물건 날아오기, 간식 나타나기, 꽃가루, 캐릭터 살랑거리기 |

## 새 그림

임시 그림으로 먼저 구현했고, 아트팀 그림이 오면 같은 파일 이름으로 바꿔 끼워요. 요청 내용은 [아트팀 전달사항](../전달/4_아트팀_전달사항.pdf)에 있어요.

## 사운드

팀원이 준비해요. 없는 파일은 조용히 넘어가도록 연결해 뒀어요. 요청 내용은 [사운드팀 전달사항](../전달/12_사운드팀_전달사항.pdf)에 있어요. 소리 없이도 이해되게 만들어요.

## 플레이 환경

아직 정해지지 않았어요. 터치와 마우스 모두 동작하게 만들어요.

## 작업 나누기

| 순서 | 세션 | 범위 | 끝난 상태 |
|---|---|---|---|
| 1 | 흐름 · 대화 | 화면 1~3, 6~8 구조, 대화 시스템, 대사, 채점표, 필요한 그림 목록 | 글 위주 화면 없이 끝까지 플레이됨 |

| 3 | 사운드 | 요청 목록, 재생 코드, 받은 파일 연결 | 파일 유무와 상관없이 동작하고 받은 소리가 들림 |
