# 엉뚱한 물건 제작

물건별로 돌려주는 그림을 Codex로 만들어 Unity에 연결한 작업 기록이에요. **57장 모두 연결을 마쳤어요.** 작업에 쓴 `Assets/TempArt`는 정리하며 지웠어요. 그림을 다시 만들 때는 빈 작업 폴더를 만들고, `Assets/Sprites`의 물건 원본을 `Original-물건.png` 이름으로 복사한 뒤 아래 프롬프트의 경로를 바꿔 쓰면 돼요.

마지막 갱신: 2026-11-04

## 게임 규칙

그림을 판정 기준별로 맞음(O) · 틀림(X)으로 나눠, 그 조합에 정해진 물건을 돌려줘요. 기준이 n개면 경우의 수는 **2ⁿ**이에요.

| 판정 결과 | 도깨비가 가져오는 것 |
|---|---|
| 전부 맞음 | 원본 A |
| 일부만 맞음 | 닮았지만 틀린 A' |
| 전부 틀림 | 완전히 다른 물건 B |

## 판정 기준

| 물건 | 요소 | 맞음 기준 | 틀린 모습 |
|---|---|---|---|
| 방망이 | 형태 | 긴 손잡이 + 더 굵은 머리 + 돌기 | 대파 |
| 가방 | 형태 | 네모 몸체 + 위쪽 손잡이 + 앞주머니 | 동그란 몸체 |
| 가방 | 패턴 | 주머니 안 가로 줄무늬 | 줄무늬 없음 |
| 돗자리 | 형태 | 사각형 외곽 | 둥근 타원형 |
| 돗자리 | 패턴 | 띠 네 줄 | 띠 다섯 줄 |
| 돗자리 | 삼원색 | 위에서부터 파랑 · 빨강 · 노랑 · 파랑 | 빨강 띠가 노랑 |
| 김밥 | 형태 | 둥근 검은 김 테두리 | 김 없음 |
| 김밥 | 패턴 | 위에 재료 둘, 아래에 재료 하나인 배치 | 초록 재료가 위 |
| 김밥 | 삼원색 | 노란 단무지 | 단무지가 파랑 |
| 김밥 | 2색 혼합 | 초록 시금치 | 시금치가 파랑 |
| 친구 | 형태 | 양 갈래 머리 | 단발 |
| 친구 | 패턴 | 멜빵바지 주머니의 천 조각 | 천 조각 없음 |
| 친구 | 삼원색 | 파란 바지 | 바지가 빨강 |

| 친구 | 3색 혼합 | 갈색 머리 | 머리가 주황 |

## 작업 순서

1. Codex에서 작업 폴더를 지정하고, 아래 프롬프트를 붙여 넣어요.
2. 그림 57장이 작업 폴더에 폴더 없이 저장돼요.
3. 그림을 확인하고 배경을 지운 뒤 `Assets/Sprites/단계 폴더`에 넣어 Unity에 연결해요.
