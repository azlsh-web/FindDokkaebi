## 대사 수정 받기

기획자에게 수정표를 보내고, 돌려받은 파일을 아래 명령으로 검사한 뒤 반영해요. 반영하면 대사 트리와 수정표도 새로 만들어져요.

```bash
python Tools/docs/apply_dialogue_edits.py 받은파일.xlsx
```

```bash
python Tools/docs/apply_dialogue_edits.py 받은파일.xlsx --apply
```

## 문서 갱신

게임이 바뀌면 아래 명령 하나로 자동 문서를 전부 다시 만들어요. AI 판정은 보내지 않아요. Unity가 켜져 있어야 사진이 찍혀요. 약 6분 걸려요.

```bash
python Tools/docs/update_docs.py --shots
```

- **자동 문서:** 게임 플로우, 사진, 대사 트리, 대사 수정표, 아트팀 · 사운드팀 전달사항, 아키텍처, 아트 구조.
- **문서가 게임과 어긋나면:** 도구가 멈추고 알려 줘요. 예를 들어 소리 이름을 코드에서 바꾸고 요청 목록을 안 고치면 멈춰요.
- **자동으로 안 되는 것:** 기획 변경 기록, 연출 개편 기획, 할 일, 아키텍처 설명 글은 사람이 판단해서 고쳐요. 링크로 공유한 페이지도 다시 올려야 해요.

### 커밋할 때 자동으로 하기 (켜야 동작해요)

아래 설정을 켜면 게임 파일이 바뀐 커밋에서 위 명령이 자동으로 실행되고, 다시 만든 문서가 그 커밋에 함께 들어가요. 저장소마다 한 번만 켜면 돼요.

```bash
git config core.hooksPath .githooks
```

| 바뀐 것 | 자동으로 하는 일 |
|---|---|
| 게임 코드, 씬, 그림, 단계 데이터, 소리, 글꼴 | 플로우 사진을 다시 찍고 자동 문서 전부 다시 만들기 (약 6분) |
| 문서 스크립트와 데이터 | 사진 없이 문서만 다시 만들기 (약 1분) |

Unity가 꺼져 있거나 Play 중이면 경고만 하고 이전 사진을 그대로 써요.
