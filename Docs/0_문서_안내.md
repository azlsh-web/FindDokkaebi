## 문서 다시 만들기

스크립트는 `Tools/docs`에 있어요. 어느 것도 AI 판정을 보내지 않아요.

게임 플로우는 Unity에서 `Tools → 찾아라도깨비 → 게임 플로우 사진 찍기`를 실행한 뒤 만들어요. 전달 문서는 이 사진을 함께 써요.

```bash
python Tools/docs/make_flow_doc.py
```

```bash
python Tools/docs/make_dialogue_tree.py
```

```bash
python Tools/docs/make_art_request.py
```

```bash
python Tools/docs/make_sound_request.py
```

```bash
python Tools/docs/make_arch_doc.py
```

```bash
python Tools/docs/make_art_structure.py
```
