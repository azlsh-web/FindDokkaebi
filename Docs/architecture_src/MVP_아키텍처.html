5단계 전체 · Unity 6.3 LTS · 씬 1개 + 패널 8개 · 스크립트 7개 · OpenAI 판정 (키 없으면 테스트 입력)

1. 플레이 흐름 (GameManager 의 State)

화면을 바꾸는 방법은 하나: ShowPanel(패널) — 그 패널만 켜고 나머지 7개는 끕니다. 간식은 단계마다 3개, 제출(또는 향이 다 탐)할 때 1개 사용. AI 판정 오류가 나면 간식을 돌려주고 Draw 로 돌아가 같은 그림을 다시 제출합니다.

2. 구성 요소와 의존 관계

화살표 = "누가 누구를 부르는가". DrawingBoard · ColorMixer · OpenAIJudge 는 GameManager 를 모릅니다. 결과는 콜백(onDone, OnMixed)으로 돌려줘서 따로 고치거나 재사용하기 쉽습니다.

5. AI 판정 (OpenAIJudge)

요청  POST https://api.openai.com/v1/responses       Authorization: Bearer {UserSettings/OpenAI.json 의 apiKey}
{ "model": "gpt-6-luna",
  "input": [{ "role": "user", "content": [
      { "type": "input_text",  "text": BuildPrompt(stage) },            ← 기획서 부록 B 형식 (역할·대상·특징·원칙·출력형식)
      { "type": "input_image", "image_url": "data:image/png;base64,..." } ← board.Texture.EncodeToPNG()
  ]}],
  "text": { "format": { "type": "json_object" } } }

응답  output[] → type "message" → content[] → type "output_text" → text =
{ "inputStatus": "ok",
  "features": [ { "featureId": "F1", "status": "present",  "evidence": "가늘고 긴 손잡이가 있다." }, ... ],
  "inputIssue": "" }

변환  present[i] = (features 중 id == stage.features[i].id 인 것의 status == "present")    uncertain → 빠뜨림 + "(애매함)"
상황처리
키 없음 / 자동 테스트IsReady = false → 체크박스 테스트 입력
연결 실패 · 키 오류 · 시간 초과(40초)onError → 간식 +1, 제출 횟수 −1, [그림으로 돌아가 다시 제출] (그림·남은 시간 유지)
JSON 이 아님 · 특징 누락 · insufficient위와 같음
기다리는 동안도깨비가 갸웃갸웃 (SimpleAnim Sway), "쪽지를 들여다보는 중..."
