# 사운드 요청 목록

연출 개편에 필요한 소리예요. 파일을 받으면 `Assets/Resources/Sound` 폴더에 아래 이름 그대로 넣기만 하면 게임에서 바로 나요. 없는 파일은 조용히 넘어가서, 소리가 일부만 있어도 게임은 그대로 돌아가요.

마지막 갱신: 2026-11-04

- **마감:** 2026-11-08(일) 출품 전. 도착하는 대로 넣어요.
- **파일 형식:** `.wav` 또는 `.ogg` (`.mp3`도 돼요)
- **라이선스:** 무료 음원이면 출처와 사용 조건을 함께 적어 주세요. 출품 · 전시에 쓸 수 있는 것이어야 해요.
- **소리 없이도 이해되게** 만들었으니, 전시장 환경에 맞게 음량만 조절하면 돼요.

## 배경음 (반복 재생)

| 파일 이름 | 나오는 곳 | 느낌 |
|---|---|---|
| `bgm_room` | 시작, 대화, 관찰 | 따뜻하고 아기자기한 아침 |
| `bgm_draw` | 그리기 | 가볍게 긴장되는, 집중을 방해하지 않는 곡 |
| `bgm_judge` | 판정 대기 | 도깨비가 두리번거리는 장난스러운 곡 |
| `bgm_picnic` | 이야기 종료 | 신나는 소풍 곡 |

## 효과음

| 파일 이름 | 나오는 때 | 느낌 |
|---|---|---|
| `sfx_tap` | 대사 넘기기, 버튼 | 짧고 가벼운 톡 |
| `sfx_talk` | 대사 글자가 나올 때 | 아주 작고 짧은 틱 (자주 나와요) |
| `sfx_count` | 관찰 숫자 3, 2, 1 | 짧은 똑딱 |
| `sfx_snack_in` | 간식 3개가 들어올 때 | 샤샤샥 |
| `sfx_submit` | 다 그렸어! | 쪽지를 건네는 소리 |
| `sfx_step` | 도깨비가 뛰어나갈 때 | 통통 발소리 |
| `sfx_item` | 물건이 나타날 때 | 뿅 |
| `sfx_success` | 전부 맞았을 때 | 밝은 짠 |
| `sfx_fail` | 틀렸을 때 | 어이없는 띠용 |
| `sfx_mark` | 채점표가 나올 때 | 연필로 슥슥 긋는 소리 |
| `sfx_land` | 소풍 장면에 물건이 놓일 때 | 톡 |
| `sfx_cheer` | 이야기 종료 | 작은 환호 |

`sfx_land`는 파일이 오면 물건이 놓이는 순간에 맞춰 연결할 예정이에요.
